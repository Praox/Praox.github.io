# Rémy Labarre — Engineering portfolio

Static portfolio based on LABARRE_Hands-on projects.pdf. All eight main projects, team experience, images and original video links are included.

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Publish with GitHub Pages

1. Create a public repository named `Praox.github.io` on the `Praox` account.
2. Upload the contents of this directory to the repository root.
3. In Settings → Pages, choose “Deploy from a branch”, then `main` and `/ (root)` and save.
4. GitHub Pages will display the site address when deployment completes.

No build, dependencies or external fonts are needed. Edit index.html for content, style.css for appearance, script.js for the image viewer. Images and the original portfolio PDF are in assets/.

External video links preserve those supplied in the PDF; viewing them depends on their original sharing settings.
